# O‘zbek alifbosi konvertori

Eski lotin, yangi lotin (Ö, Ğ, Ş, Ç) va kirill yozuvlari o‘rtasida matn va fayllarni (`.txt`, `.docx`, `.pdf`, `.md`, `.csv`, `.srt`, `.html`, `.json`) almashtiradigan bitta sahifali vosita. Hammasi brauzerda ishlaydi, fayllar hech qayerga yuborilmaydi.

Saytni GitHub Pages orqali yoqing: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
